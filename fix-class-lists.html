Add missing students to their classes

Students added during a register used to stay on that register only — they were never written into the class list, so the class size never grew and the teacher had to add them again each week. This finds everyone in that position and puts them in their group.

Upload the latest index.html first. From that version on, a student added during a register joins the class automatically. This tool is only for the ones added before that, under the old behaviour.

Step 2 — Save a copy of the timetable

Downloads schedule-before-adding-students.json. Step 3 stays locked until you do. It is the way back if anything looks wrong.

Step 3 — Add them

Only adds names to class lists. No register is changed, no student is removed, nothing else in the database is touched.
