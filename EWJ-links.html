Every day

Registers, briefings, feedback
Attendance Register /ewj-attendance/ Take the register, manage groups, add, move, search or remove students Morning Briefing EWJ-morning.html The day ahead — classes, absences, what needs chasing Feedback Generator feedback-generator.html Turns teachers' lesson comments into parent feedback. Needs your Claude API key

Start of year

Run once, then leave alone
Load a new timetable update-schedule.html Backs up the current timetable, shows what changes, then applies it. Run outside class hours Add rooms to the timetable add-rooms.html Puts a room and its seat count on every class. Only adds fields — student lists untouched. Rooms show in the admin view only, never to teachers Reset absences for a new course reset-absences.html Archives every register to file, then clears them so the year starts clean. Can restore

Now and then

Reporting and repairs
Reports ewj-reports.html Attendance reports and student progress summaries Cleanup Tool cleanup.html Removes duplicate records — run only if duplicates appear

Behind the scenes

Where it all lives

If a page looks out of date, check the address bar. An address starting file:///Users/… is a copy sitting on that one computer — it won't match what your teachers see and it won't update. Only https://johnsmithenglishteacher-blip.github.io/… is the live tool.

End of course

  • Export the final CSV from the History tab for your records
  • Lock the database: Firebase → Realtime Database → Rules → set .read and .write to false
  • Keep the API key private — never commit it to the repository, which is public
